GCET Jammu beginner-level Web Technology project. HTML + CSS only; no JavaScript. Uses Box Model, Flexbox, Grid, CSS Variables, hover effects, typography and media queries. Real GCET photographs and faculty photographs are loaded from official GCET URLs, so internet is required.

The HTML and CSS have been written in multiple lines with simple class names so they are easy to understand and explain in Web Technology lab.
No JavaScript is used.
