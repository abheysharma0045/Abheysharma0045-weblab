GCET Jammu Intermediate Web Technology Website

This version follows the lab assignment using ONLY HTML and CSS.
No JavaScript file or JavaScript functions are used.

Pages:
- index.html — Home
- about.html — About College, Vision, Mission
- faculty.html — 6 faculty cards
- students.html — Student table
- gallery.html — 6 real GCET campus photos using CSS Grid
- admission.html — Student Admission Form
- style.css — external CSS

CSS concepts used:
- Box Model
- Flexbox navigation and layouts
- CSS Grid for departments, gallery, faculty and form
- Typography
- CSS variables
- Hover effects
- Media queries for responsive desktop/tablet/mobile design

Mobile navigation uses a CSS checkbox/label technique, so JavaScript is not required.
Real GCET photographs are loaded from the official GCET Jammu website, so internet is needed for those images.
